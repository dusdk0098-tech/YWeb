## 결정 필요 (구현 보류)

1. **사전점검 오류 시 마감 차단** — 원본 SC는 막았다. 지금은 확인창만. 막으면 기존 원장 마감과 마감 시험 10개 파일·E2E가 함께 바뀐다.
2. **사진대지** — 인계문서가 검역·디코딩·EXIF 정책 승인 전 이미지 표시를 금지한다.
3. **법정 서식 출력** — 원본 xlsm 양식과의 동등성 기준(문서 순서·쪽 나눔·셀 위치·허용 차이)이 필요하다. 원본 내역집계표의 8번(본사) 열 누락이 의도인지도 확인 필요.
4. **교육·일지 재설계** — 인계문서의 제안은 현재 v1에 없는 메타데이터(적용대상·권리 검수)나 전면 화면 재설계를 수반한다.
5. **SEC-LOCAL-01** — OS별 권한 대책은 승인 후.
