# SC 법정 서식 출력 동등성 기준안 (미승인 제안)

**상태: 제안. 사용자 승인 전 구현하지 않는다.** 인계문서(LEGACY_APP_FEATURES §1 출력, 02 수용 기준)는 원본 xlsm 양식과의 동등성 기준을 먼저 정하라고 했다. 이 문서는 원본 소스에서 확인한 사실과, 결정할 기준을 모은 것이다.

## 원본 SC 출력(소스 확인, 원본 앱 실행 안 함)

근거: 로컬 PEDIT-SC 0.3.10 소스 `src/output-layout.js`, `src/excel-export.js`, `src/excel-*.js`, `renderer/modules/constants.js`.

- **방식:** `assets/blank-template.xlsm`(164,503바이트)을 PowerShell + Excel COM으로 열어 셀 값을 채우고 `.xlsm`으로 저장한다. 선택하면 같은 통합문서를 PDF로 변환한다. 웹 서버에서는 Excel COM을 쓸 수 없다.
- **문서 순서:** 표지 → 내역집계표 → 사용내역(갑) → 총괄 → 사용내역(을) → 항목 1~9 상세 → 사진대지(신호수 → 안전보호구 등 → 안전시설비 등 → 기타). 증빙목록은 쪽 번호 없는 별첨이다.
- **쪽 나눔(한 쪽 수용량):**

| 문서 | 1쪽 수용량 | 빈 경우 |
|---|---|---|
| 내역집계표 | 16개월 | 1쪽 |
| 사용내역(을) | 항목별 행 범위(1: 7행, 2: 9행, 3: 6행, 4·8·9: 1행, 5·6·7: 2행). 가장 많은 항목 기준으로 쪽 수 결정 | 1쪽 |
| 1. 인건비 ~ 9. 위험성평가 | 22 / 28 / 22 / 9 / 16 / 11 / 8 / 3 / 8행 | 1쪽 |
| 사진대지 분류별 | 2장 | 쪽 없음 |

- **확인 필요:** 내역집계표 열 매핑에서 8번(본사사용비)이 빠져 있다(`src/excel-summary-settings.js` 118행 부근). 양식이 의도한 것인지 결함인지 모른다.

## 선택지

### A안 (권장): HTML로 같은 문서 순서·쪽 나눔·값을 재현

- 위 문서 순서와 쪽 수용량을 그대로 따르는 HTML 인쇄 화면을 만든다. 새 의존성이 없고, 브라우저 인쇄로 PDF를 만든다.
- **동등성 기준(제안):**
  1. 문서 순서와 각 문서의 쪽 수가 원본 규칙과 같다(자동 시험).
  2. 각 쪽의 모든 숫자·날짜·문자 값이 원본이 같은 입력으로 채우는 셀 값과 같다. 원본 셀 값 목록을 합성 fixture로 뽑아 대조한다(자동 시험).
  3. 표의 행·열 구성과 제목은 원본 양식과 같다. 셀 크기, 글꼴, 테두리 같은 모양은 "근사"로 두고, 알PDF에서 사람이 한 번 확인한다.
- **허용 차이:** 엑셀 파일(.xlsm)은 만들지 않는다. 모양은 근사이며, 값과 쪽 구성만 일치를 보장한다.

### B안: 원본 xlsm 양식에 값 채우기

- 서버에서 xlsx 라이브러리(예: exceljs)로 `blank-template.xlsm`에 같은 셀 값을 채워 엑셀 파일로 내려준다. 모양까지 원본과 같다.
- **필요한 승인:** 새 의존성 추가, 양식 파일을 저장소에 넣어도 되는지(권리·출처), 매크로 포함 파일 처리 정책이 필요하다. PDF는 Excel이나 LibreOffice가 없으면 만들 수 없다.

### C안: 현재 유지

마감본 HTML 인쇄만 유지한다. 법정 서식과는 다르다.

## 결정이 필요한 것

1. A / B / C 중 선택.
2. A안이면 위 동등성 기준 1~3과 허용 차이 승인.
3. 내역집계표 8번(본사) 열 누락: 원본 그대로 둘지, 8번 열을 넣을지.
4. 첫 범위. 권장: 표지, 내역집계표, 사용내역(갑), 총괄을 먼저 하고 그다음 사용내역(을)과 항목 1~9를 한다(사진대지는 이미 분류별 인쇄가 있음).

## 승인 후에도 PASS로 표시하지 않을 것

알PDF 실제 출력, 원본 앱으로 만든 실제 xlsm과의 육안 대조, 고용노동부 고시 서식 적합성 판단(법적 판정은 하지 않음).
