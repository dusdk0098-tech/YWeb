# 화면 문구 정책 · 용어집

UI 개편 3단계(`docs/UI_REDESIGN_PLAN.md` 4-3)의 기준이다. 화면 문구를 고치는 PR은 이 문서를 따른다.

## 1. 안내문

- 화면 제목 아래 안내는 **한 줄**만 보인다. 나머지는 `Notice`(`src/ui`)의 `자세히` 안에 접는다.
- 면책·"법적 판정 아님"·"인증 아님" 문장은 **지우지 않는다**(AGENTS.md). 문장 그대로 `자세히` 안으로 옮긴다.
- 보이는 한 줄은 사용자가 지금 알아야 할 사실 하나를 쉬운 말로 쓴다. "~이 아닙니다"를 늘어놓지 않는다.
- 긴급 대응처럼 안전과 바로 이어지는 문장은 접지 않고 보이는 한 줄에 둔다(`tone="warning"`).
- 제목 위 영문 머리말(`TOOLBOX MEETING`, `VERSION 2` 같은 eyebrow)은 쓰지 않는다.
- 페이지 넘김 버튼은 `이전 50` / `다음 50`(수가 없으면 `이전` / `다음`). 인쇄 링크는 `○○ 인쇄 / PDF`. 화살표(↗) 꼬리표는 쓰지 않는다.
- 공학 계산 경고(P-02)는 화면 위에 그대로 둔다(사용자 결정).
- 인쇄물·PDF 문구는 이 정책 대상이 아니다. 인쇄에 들어가는 면책은 바꾸지 않는다.
- 확인 창(`window.confirm`) 문구는 이번 단계에서 바꾸지 않는다(UI 5단계에서 공통 확인 창으로 교체).

## 2. 내부 값

| 값 | 상세 화면 | 목록 행 |
|---|---|---|
| 기록·계정 UUID, 이전 기록 ID | `TechDetails`("기술 정보")에 접기 | 보이지 않음 |
| 버전 `v3` | `TechDetails` | 보이지 않음(버전이 곧 이름인 곳은 예외: 비용 월 버튼, 작업중지 상태 제목) |
| SHA-256 해시 | `TechDetails` | 보이지 않음 |
| 사람 이름·날짜·정정 사유 | 보임 | 보임 |

## 3. 용어

| 지금 쓰는 말 | 바꿀 말 | 비고 |
|---|---|---|
| 참조 취합 | 내용 확정 준비 | 화면별 적용 PR에서 |
| 명시 연결목록 | 연결된 지출 | 비용 |
| 미검사 원본 | 원본 파일 | 검사하지 않는다는 사실은 `자세히`에 남긴다 |
| 보관 | 확정 보관 | 일지·교육 |
| 수기 ○○ | ○○ | 메뉴에서는 2단계에서 정리됨 |

상태 칩은 `작성 중 · 제출됨 · 확정 · 보관 · 정정 초안` 다섯 가지로 맞춘다.

### 외부 접속 마법사 (docs/SELF_HOSTING.md)

| 쓰는 말 | 뜻 · 쓰는 곳 |
|---|---|
| 완료 · 아직 안 됨 · 확인 불가 · 확인 중 | 마법사 단계 상태 칩. "확인 불가"는 앱이 확인할 수 없는 경우(인터넷 끊김, 이 OS의 방화벽 등) |
| 다시 확인 · 모두 다시 확인 | 단계 점검을 다시 돌리는 버튼 |
| 공유기에 80·443 열기 · Cloudflare에 만들기 · A 레코드 만들기 | 앱이 대신 하는 버튼. 실패해도 수동 값은 같은 자리에 남는다 |
| 관리자 권한으로 실행 | 화면에 보인 명령 하나를 Windows 권한 확인 후 실행 |
| 덮어쓰기 | 기존 DNS 레코드가 다른 값일 때만 보이는 버튼 |
| 다시 시작해 적용 · 설정 적용 | 마법사 하단 적용 버튼(`start.cmd`로 켠 경우 앞의 것) |
| 처음부터 | 마법사 입력만 지운다. 이미 적용한 외부 접속 설정은 그대로 |
| 외부 접속 설정 열기 | 홈 상태 줄의 버튼. 고칠 단계로 이동 |
| 고급: 직접 입력 | 마법사 아래 접힌 기존 입력 폼 |
